# Pet Care Log

A simple, user-friendly web application designed to help pet owners track and manage their pets' daily routines, health records, feeding schedules, and veterinary visits in one convenient place.

## Features
* **Pet Profiles:** Add and manage details for multiple pets (name, breed, age, and weight).
* **Daily Activity & Feeding Logs:** Keep track of meal times, walks, and daily care routines.
* **Health & Vet Tracker:** Record vaccination dates, medications, and upcoming vet appointments.
* **Responsive Design:** Works smoothly across both mobile and desktop browsers.

## How to Install and Run

### Option 1: View Live Online
Since this project is hosted on GitHub Pages, you can access it directly in your browser without installing anything:
1. Open your web browser.
2. Go to: `https://krazyjp2.github.io/JohnPaulApilado.github.io/`

1. **Clone the repository:**
      ```bash

   ```
2. **Navigate to the project folder:**
   ```bash
   cd JohnPaulApilado.github.io
   ```
3. **Launch the app:**
   Open the `index.html` file directly in any web browser (Chrome, Edge, Safari, or Firefox).
